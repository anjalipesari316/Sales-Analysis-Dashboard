📊 Sales Analysis Dashboard

📌 Project Overview
This project presents an interactive Sales Analysis Dashboard created using Microsoft Power BI.
The dashboard helps analyze sales performance and identify important business trends using interactive visualizations and KPIs.

🛠️ Tools & Technologies
- Power BI
- Power Query
- DAX
- Excel / CSV
- Data Visualization

📈 Dashboard Features
- Total Sales
- Total Profit
- Total Orders
- Sales by Category
- Sales by Region
- Sales by Segment
- Monthly Sales Trends
- Profit Analysis
- Interactive filters and slicers

📂 Files
- "Sales_Analysis_Dashboard.pbix" – Power BI dashboard
- "Sample-superstore.csv" – Dataset used for analysis
- "Dashboard_Screenshot.png" – Dashboard preview

🎯 Project Objective
The objective of this project is to analyze sales data, understand business performance, identify trends, and present meaningful insights through an interactive dashboard.
